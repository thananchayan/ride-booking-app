# Ride Booking Application

## Tech Stack

### Backend
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Swagger OpenAPI

### Frontend
- React
- React Router
- Axios

## Features

- Driver Management
- Driver Availability Tracking
- Ride Booking
- Automatic Driver Assignment
- Validation and Exception Handling
- Swagger API Documentation

## Run Backend

```bash
cd backend
mvn spring-boot:run
```

Backend URL:

```text
http://localhost:8080
```

Swagger Documentation:

```text
http://localhost:8080/swagger-ui.html
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```
